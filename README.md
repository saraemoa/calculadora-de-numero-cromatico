# calculadora-de-numero-cromatico
 <h6>Teoria de Grafos</h6>
<br>O código desenvolvido é uma calculadora de número cromático de grafos, utilizando a linguagem C. Ele tem como objetivo encontrar o menor número de cores necessário para colorir os vértices de um grafo, de forma que nenhum vértice adjacente compartilhe a mesma cor, conhecido como problema de coloração de vértices. A entrada do programa é o nome de um arquivo .txt contendo a matriz de adjacência do grafo que se deseja analisar. O programa realiza a leitura do arquivo e processa os dados, armazenando a matriz em uma estrutura adequada. Para encontrar o número cromático, foi implementado um algoritmo de backtracking, que testa todas as combinações possíveis de cores de forma eficiente até encontrar a coloração válida com o menor número possível.<br>

- Modelo de exemplo do arquivo de entrada .txt:
  <br>0 1 1 0
  <br>1 0 1 1
  <br>1 1 0 1
  <br>0 1 1 0
